🌱 AI Smart Agriculture Assistant

An intelligent agriculture support system that combines Machine Learning, Deep Learning, and AI to help farmers make better farming decisions.

🚀 Project Overview

The AI Smart Agriculture Assistant is designed to support farmers by providing plant disease identification, crop recommendations, irrigation predictions, fertilizer suggestions, weather insights, and a bilingual AI chatbot.

✨ Key Features

- 🍃 Plant Disease Detection: CNN-based plant disease classification using leaf images.
- 🌾 Crop Recommendation: Recommends suitable crops using soil and environmental parameters.
- 💧 Irrigation Prediction: Predicts irrigation requirements based on soil moisture and weather conditions.
- 🧪 Fertilizer Recommendation: Suggests fertilizers based on crop and nutrient information.
- 🌦️ Weather Insights: Uses weather data to support farming decisions.
- 🤖 AI Chatbot: Provides agriculture-related assistance in Tamil and English.
- 📊 Data Analysis: Explores agricultural data to identify useful patterns and insights.
- 🖥️ Interactive Dashboard: Streamlit-based user interface.

🛠️ Technologies Used

- Python
- Pandas and NumPy
- Scikit-learn
- TensorFlow / Keras
- Convolutional Neural Networks (CNN)
- Matplotlib and Seaborn
- Streamlit
- Weather API
- Machine Learning and Data Analysis

To develop an AI-powered agriculture assistant that supports farmers with data-driven recommendations, early plant disease identification, and smarter resource management.

▶️ How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Configure the necessary dataset paths and API keys.
4. Run the Streamlit application.

git clone https://github.com/YOUR-USERNAME/AI-Smart-Agriculture-Assistant.git
cd AI-Smart-Agriculture-Assistant
pip install -r requirements.txt
streamlit run app.py
